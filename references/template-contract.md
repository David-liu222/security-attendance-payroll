# 模板保留与字段映射

## 总原则

将用户本次提供的考勤模板和工资模板作为唯一版式来源。创建输出副本后，只在既有数据行和既有字段中写入结果；不得删改工作表、表头、人员行、汇总行、公式区以外的单元格、页脚或底部资金区。

不要在技能包中保存包含姓名、身份证号、工资或打卡记录的模板。每次运行由用户提供当月模板。

## 考勤模板：预期字段

识别以下字段后再写入：序号、部门、姓名、岗位、身份证号、实际出勤天数、餐补天数、薪资标准（元/天）、加班天数、天数合计、当月工资、备注。

历史样表的标题为“人力行政中心安保2026年7月份出勤天数统计”，工作表名称显示为“11月”。标题与工作表名称均不得擅自更名。历史样表的“实际出勤天数”列有失效外部链接；重新生成时必须以原始考勤核验结果写入，不继承 `#NAME?`。

## 工资模板：预期字段

识别以下既有字段：

| 字段 | 用途 |
| --- | --- |
| 系数 | 固定输入，保持不变 |
| 实际出勤天数 | 来自已核对的考勤表 |
| 带薪休假天数 | 来自已确认的休假资料 |
| 总系数 | `(实际出勤天数 + 带薪休假天数) × 系数` |
| 应发/扣除/实发系数工资 | 系数工资计算 |
| 班长津贴 | 仅写入已确认的固定津贴 |
| 额外工程 | 写入本月工程奖励 |
| 部门奖励 | 只写本月部门奖励明细，不写绩效 |
| 处罚 | 非考勤类处罚 |
| 迟到及缺卡 | `(迟到次数 + 缺卡次数) × 50` |
| 工资总计 | 按模板列项目加减 |

历史工资样表中，工人数据行约在第 6—32 行，合计行约在第 33 行，底部资金区约在 I43:J46。运行时必须根据实际表头和姓名定位，而不是依赖行号；识别到该底部资金区后不得覆盖。

若本月有按总系数分配的绩效池，将个人绩效直接并入既有“应发系数工资/实发系数工资”链路，不新增列，不写入“部门奖励”。可变金额来源没有数字时，保持对应单元格空白。

## 输出与审计文件

交付两份严格格式的模板副本：`考勤表.xlsx`、`工资内部分配表.xlsx`。另交付不改变模板的审计文件（CSV、JSON 或 Markdown 均可），列出原始打卡、班次归属、迟到、缺卡、姓名匹配、工程分配和所有汇总核对结果。
