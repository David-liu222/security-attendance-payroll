# 安保工资计算规则

## 固定规则

- 迟到或缺卡：每次扣 50 元；同一天有多笔经确认的缺卡时，按缺卡笔数累计。
- 工人个人系数：以工资模板“系数”列为唯一来源，月内不得修改。
- 带薪休假：参与结算人员按月份统一计入，31天的大月为6天，30天及以下的小月为5天；有明确个别请休假资料时以该资料覆盖。在总系数中计入天数。
- 工资表中的津贴、奖励、处罚、其他等可变金额，只在来源中存在可解析数字时填写；来源空白或没有数字时保持模板单元格空白。
- 部门奖励以用户提供的奖励明细表为准。若某人不参与考勤、系数工资或绩效结算，但奖励明细表中已有该人数字，除非用户明确要求剔除该奖励，否则仍作为“仅部门奖励”写入，确保部门奖励合计等于来源表合计。

## 系数工资

```text
个人总系数 = (实际出勤天数 + 带薪休假天数) × 个人固定系数
全员总系数 = SUM(个人总系数)
系数单价 = 系数工资池 ÷ 全员总系数
应发系数工资 = ROUND(个人总系数 × 系数单价, 0)
实发系数工资 = 应发系数工资 - 扣除系数工资
```

工资池、扣除系数工资和带薪假补发金额必须从本月输入或模板明确读取；不得沿用上一月硬编码常数。

## 绩效

```text
个人绩效 = 绩效池 ÷ 全员总系数 × 个人总系数
应发系数工资 = 应发系数工资 + 个人绩效
```

绩效池不写入“部门奖励”列；它按总系数分配后直接并入既有应发系数工资/实发系数工资链路。需要控制尾差时，保留两位小数并把四舍五入差额调整到最后一名参与结算人员。

## 额外工程

```text
额外工程可分配金额 = 工程总额 - 部门留存
个人工程总系数 = 工程考勤天数 × 工程系数
额外工程应发 = ROUND(可分配金额 ÷ 工程总系数 × 个人工程总系数, 0)
```

工程系数和工程考勤天数必须以额外工程汇总表对应月份、对应工程的人员明细为准；不要用工资模板的个人系数替代。先验证“个人工程应发合计”等于可分配金额，允许仅存在由逐人四舍五入造成的尾差并单独说明。

## 工资总计

```text
工资总计 = 实发系数工资 + 带薪假 + 班长津贴 + 额外工程
         + 部门奖励 + 春节加班 + 其他 - 处罚 - 迟到及缺卡
```

“部门奖励”只写部门奖励明细，不包含绩效。“处罚”与“迟到及缺卡”必须分列：前者使用审批或处罚资料，后者只写考勤异常次数乘 50 元的结果。
